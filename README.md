# Grand Line Portfolio v0.1

打开 `index.html` 即可使用，不需要安装。若浏览器对本地文件有限制，可使用 `python -m http.server 8080`，打开 http://localhost:8080 。

## 已实现
- CNY 总览、日版卡牌持仓、数量/版本/卡号/品相备注、买入和市场价记录。
- 支持三字母 ISO 4217 币种；使用 Frankfurter 免费 API 获取**买入日**与**当前**对 CNY 汇率；若不可用则手工输入。
- 市值、盈亏、百分比、历史快照趋势图；导出和导入 JSON 备份。
- 集换社价格手动填写，不执行受限制抓取。
- OPTCG API 英文版查询是实验性辅助，不自动覆盖日版价格。

## 重要限制
当前数据仅在同一浏览器 localStorage 中持久化。清理浏览器数据可能会删除记录，请定期导出备份。此版本**没有**部署、账户登录或真正跨设备同步。浏览器实时汇率可能因网络/CORS 或 API 可用性失败，会提示手工汇率。

## 部署与同步后续计划
部署静态网站（如 Cloudflare Pages / Vercel），使用 Supabase Auth + Postgres 和行级安全策略，实现多设备同步。创建私有项目、配置密码登录、限制每条记录 `auth.uid() = user_id`、后端保密密钥只保存在服务器环境。此项必须在持有者配置外部账户并完成部署后才能实际启用。

## 估值说明
市场价按数量计算；卡牌总买入价（而不是单价）参与成本计算。历史买入汇率固化；市场价换算可刷新当前汇率。资产快照是按天保存的真实录入状态，不会补造未保存日子的行情。若不新增快照，历史曲线不会变化。OPTCG API 基于英文版，价格不能用于给日版一比一估值。


## v0.2 日版卡号识别
Netlify Functions `card-lookup` 在服务端查询官方日版卡牌列表，添加卡牌时输入卡号点击“根据卡号识别”。官方结构变化、网络故障或有多个插画版本时须手动核对；SAMPLE 卡图仅供识别，版权属于权利人。集换社暂无已核实授权接口，仍通过手动录入参考价。云同步仍未实现。
